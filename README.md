# Fisiolife Fisioterapia & Pilates

Site institucional da Fisiolife em Ibiúna, desenvolvido com Next.js, React, TypeScript e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Validação e produção

```bash
npm run lint
npm run build
npm start
```

As informações institucionais, links, telefone, endereço e URLs de conversão estão centralizados em `src/lib/site-config.ts`.
